# Description: Unique anchor verification, atomic in-memory validation, documentation/help/--agents sync, and pre-commit checks
- **Edit & pre-commit verification:** When editing files programmatically, verify that each search anchor occurs uniquely (`count == 1`), prefer targeted `text.replace(old, new, 1)` patches over rewriting entire files as a single literal, validate all search anchors and syntax in memory before writing any file to disk (so a failed check leaves the working tree untouched), and avoid raw multiline strings that could break chat Markdown fences. Keep `README.md`, `AGENTS.md`, user-facing help (`-h`/`--help`), and agent instructions (`--agents`) in sync within the same commit when changing behavior, options, or rules. Before committing, always run syntax/linter checks and the local unit test suite.
