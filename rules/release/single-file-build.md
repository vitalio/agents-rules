# Description: Single-file executable build from modular src/ via build.py and local reinstall
- **Single-file build from modular `src/`:** Edit source modules and assets under `src/` rather than hand-editing the generated standalone executable. Whenever `src/`, `install.sh`, or `install.ps1` is modified, keep `VERSION` and `VERSION = "..."` in `src/header.py` in sync, run `python3 build.py` to regenerate the standalone executable, verify `python3 build.py --check`, and reinstall locally via `sh install.sh --yes >/dev/null` before committing.
