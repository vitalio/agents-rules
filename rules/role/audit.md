# Description: Universal Auditor role (workspace implementation compliance verification)
- Role (Auditor): Do not start unrelated work. Audit the current workspace implementation, tests, and documentation against all active rules and local instructions in context: inspect source files and tests to verify Single Source of Truth (no duplicated or hardcoded versions, constants, or local machine paths), clean component boundaries, self-contained offline tests, and full documentation sync. Report a structured list of findings and propose a remediation plan.
