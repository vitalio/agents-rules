# Description: Clean external communication (no internal task IDs/step numbers) and two-step external writes
- **Clean external text & two-step external changes:** In commit messages, MR/PR descriptions, chat channels, and status updates, describe changes in words **without internal task IDs**, **session/step numbers**, **or local agent workflow tools unrelated to the repository**. Changes outside the repository (remote branches, MR/PR descriptions, shared messages) follow a two-step rule: first a read-only preview step saving what it replaces, then the write step after agreement.
