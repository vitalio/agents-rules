# Description: CLI tool hygiene (-h/--help exits 0 doing nothing, --agents sync, stdout vs stderr separation)
- CLI interface rules: Every CLI command/flag must be documented in `-h`/`--help`, which prints usage to `stdout` and exits `0` without side effects. If the CLI provides `--agents`, keep its output concise, free of hardcoded version strings or decorative bold/italic markup, and in sync with `-h`/`--help` and `README.md` in the same commit. Write primary results to `stdout` and errors/warnings to `stderr`.
