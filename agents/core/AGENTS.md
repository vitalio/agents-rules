# `agents/core/` — Universal Agent Axioms

- Scope: Foundational epistemic, structural, and operational axioms that hold
  across all domains (software engineering, research, documentation,
  operations).
- Invariants: A rule belongs in `agents/core/` only if it is completely
  independent of operating system, version control system, programming
  language, and external tools.
- Style: Express each axiom in 1-3 plain-text bullet points
  (`- Topic: instruction.`) without decorative bold/italic markup.
