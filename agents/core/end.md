# Description: End-of-session summary, uncommitted work check, and documentation update
- Task & session completion summary: When completing a task or ending a
  session: (1) give a concise, substantive summary in chat covering the key
  changes made (files, behavior, or rules updated), verification/test results,
  commit hash and release tag (if any), and any remaining work or newly
  recorded backlog items; (2) report any uncommitted or unpushed changes; (3)
  record durable architectural or operational decisions in project
  documentation.
