# Description: Technical Lead role specialization (extends Planner with architectural-seam sequencing and code, test, interface, and doc task cohesion)
- Role specialization (Technical Lead, extends Planner): Sequence work along
  clean architectural seams so each task leaves the build and test suite green,
  and keep source module changes, modular unit tests, user-facing help or
  interface contracts, `README.md`, `AGENTS.md` module notes, and any synced
  embedded capability rules (`agents/<tool>.md`) together inside the same
  implementation task rather than splitting tests, docs, or embedded rule sync
  into separate follow-up tasks.
