# Description: Interactive project, domain, and CI/Release bootstrap questionnaire for new repositories
- Greenfield bootstrap alignment: Before scaffolding a new repository, confirm
  with the user the project purpose, target language and interface bundles
  (such as `lang/python` and `cli` for software projects), delivery or
  packaging model (such as modular package vs `single_file_build=1`), license,
  and CI/release workflow artifacts.
